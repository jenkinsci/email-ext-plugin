Send email through the Amazon SES v2 SendEmail API over HTTPS instead of connecting to an SMTP server. The message is built exactly as it would be for SMTP (HTML, attachments, pre-send scripts and emergency reroute all apply) and is submitted to SES as a raw MIME message. When this is enabled the SMTP server, port, credentials, SSL/TLS, OAuth 2.0 and advanced email properties are ignored.

The AWS identity used must be allowed ses:SendEmail and ses:SendRawEmail, and the sender address must be a verified SES identity. While the SES account is in the sandbox, recipients must be verified as well.

The post-send script is still executed, but its transport variable is null.
